# 인천 입지 분석

업종과 전략을 정하면 격자 후보지를 점수로 줄 세우는 Streamlit 앱입니다.
인천시를 나눈 6,239개 격자의 카드 결제 집계 데이터를 사용합니다.

## 데이터 준비

`data/` 폴더에 넣으십시오. 저장소에는 코드만 있습니다.

| 파일 | 필수 |
|---|---|
| `output_with_weekend.parquet` | 필수 |
| `revisit_output_syn.csv` | 선택 (없으면 재방문율 지표만 빠짐) |

## 실행

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

## 구조

```
app.py         UI — 지도, 후보 목록, 격자 상세, 지표 설명
site_data.py   wide parquet -> 롱 포맷 변환, GeoJSON 생성
scoring.py     점수 계산 (순수 함수, Streamlit 비의존)
```

`scoring.py`는 파일 입출력과 Streamlit에 의존하지 않습니다.
합성 데이터로 로직만 따로 검증할 수 있게 하기 위해서입니다.

## 점수 계산 방식

여섯 개 요소를 각각 **백분위(0~1)** 로 바꾼 뒤 가중 평균해 100점으로 환산합니다.
단위가 다른 지표를 그대로 더하지 않기 위해서입니다.

| 요소 | 계산 |
|---|---|
| 시장 규모 | 해당 업종 `amt_sum` 백분위 |
| 상권 집중도 | 해당 업종 `gi_star` 백분위 |
| 성장 여지 | `gi_star` 백분위 − `amt_sum` 백분위 |
| 업종 특화도 | LQ = (격자 업종 비중) ÷ (인천 전체 업종 비중) |
| 재방문율 | `revisit_rate` 백분위 |
| 타겟 적합도 | 선택한 연령·성별·거주지 비중 합의 백분위 |

지역을 좁히면 **그 지역 안에서 다시** 백분위를 매깁니다.
인천 전체 기준으로 줄을 세우면 저밀도 지역이 전부 하위권이 되어
구 단위 비교가 무의미해지기 때문입니다.
단, 해당 구의 격자가 20개 미만이면 전체 기준을 유지합니다.

### 성장 여지

`gi_star`는 이웃 격자를 포함한 국지 통계입니다.
그래서 **Gi\* 백분위는 높은데 본인 결제액 백분위는 낮은** 격자가 존재합니다.
주변은 활발한데 이 자리는 아직 약하다는 뜻이며, 진입 여지의 대리 지표로 씁니다.

다만 그 자리가 약한 데는 접근성이나 건물 사정 같은 이유가 있을 수 있습니다.
지표가 이유까지 말해주지는 않습니다.

### 전략 프리셋

`scoring.py`의 `PRESETS`에서 가중치를 조정할 수 있습니다.

- **성숙 상권 진입** — 시장 규모와 재방문율 중심
- **기회 상권 탐색** — 성장 여지 중심 (집중도 가중치를 낮게 유지해야 합니다.
  높이면 이미 다 큰 상권이 그대로 1위로 올라와 프리셋 취지와 반대가 됩니다)
- **단골 중심 업종** — 재방문율 중심
- **특정 고객층 겨냥** — 타겟 적합도 중심

## 이 도구의 한계

- 임대료, 권리금, 경쟁 점포 수, 유동인구, 배후 인구가 데이터에 없습니다.
- 연령·성별·업종의 **교차 집계가 없습니다.** 원본이 주변합(marginal)만 담고 있어
  "20대 여성의 카페 매출"은 계산할 수 없습니다. 격자 상세의 고객 구성은
  선택한 업종이 아니라 그 격자 **전체 매출** 기준입니다.
- 점수는 절대 평가가 아니라 선택한 범위 안에서의 **상대 순위**입니다.
- 결제 결과 데이터이므로 과거를 설명할 뿐 미래를 보장하지 않습니다.

후보를 좁히는 데까지만 쓰고, 최종 판단은 현장 확인과 임대 조건 검토를 거치십시오.

## Gi\* 해석 주의

`gi_star`는 금액이 아니라 z-score입니다.

- `> 1.96` 유의한 핫스팟 (95% 신뢰수준)
- `> 2.58` 매우 유의한 핫스팟 (99% 신뢰수준)
- `< -1.96` 유의한 콜드스팟

"Gi\*가 3이면 매출이 3배"라는 해석은 잘못된 것입니다.
